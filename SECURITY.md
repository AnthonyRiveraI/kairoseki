# Security policy

Kairoseki is a security tool, so bypasses matter.

**Please do not open public issues for working bypasses.** Report them through
[GitHub private vulnerability reporting](https://github.com/AnthonyRiveraI/kairoseki/security/advisories/new),
ideally with a scenario for the attack lab that reproduces the leak.

You can expect a first answer within 7 days. Once a fix is released, you will be credited in the changelog and,
if you like, the scenario will join the attack lab under your name.

Supported versions: the latest release.
